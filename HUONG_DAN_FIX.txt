NGUYÊN NHÂN LỖI 500
Bản trước dùng process.cwd() và app.listen(), đồng thời Vercel chưa đóng gói
index.html/background.png/logo vào Serverless Function.

BẢN NÀY ĐÃ SỬA
- Dùng __dirname để tìm file trong function bundle.
- Bỏ app.listen(); chỉ export Express app.
- vercel.json dùng includeFiles để đóng gói:
  index.html, background.png, ahamove-logo.svg.
- Express phục vụ các file ở thư mục gốc.

CÁCH CẬP NHẬT
1. Giải nén file ZIP.
2. Upload ghi đè toàn bộ file trong ZIP lên thư mục gốc GitHub.
3. Commit.
4. Vào Vercel > Deployments và chờ deployment mới hoàn tất.
5. Kiểm tra:
   /background.png
   /ahamove-logo.svg
6. Mở trang bằng cửa sổ ẩn danh.
